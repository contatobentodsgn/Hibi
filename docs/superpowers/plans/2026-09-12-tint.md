# Tint visual do Hibi Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a local, accessible tint preference that changes Hibi's brand accent while preserving semantic category colors.

**Architecture:** Extend the existing renderer-only theme host with a closed tint preference and a root `data-tint` attribute. A new `TintSettings` component mounts once in Settings › General through the existing `NotchDisplaySettings` General-section mount, and CSS maps each allowed tint to audited semantic accent tokens in both light and dark themes.

**Tech Stack:** React 19, TypeScript, CSS custom properties, Vitest static rendering, Playwright.
